## 1. 目的與範圍

### 1-1. 目的

在**不使用雲端服務、不需要 GPU** 的情況下，把會議或影片的語音即時轉成大字幕：
中文直接顯示，英文／日文／韓文翻成繁體中文（台灣用語）並附原文，同時保存逐字稿。

### 1-2. 與參考專案的差異

| 項目 | live-subtitle（參考專案） | 本專案 |
|---|---|---|
| 語音辨識 | 雲端（OpenAI／Groq），本機 GPU 選用 | **本機 CPU**（faster-whisper INT8） |
| 翻譯 | 雲端（Claude／OpenAI／DeepL） | **本機 CPU**（NLLB-200 INT8） |
| 費用 | 依用量計費（有預算控管） | 0 元 |
| 網路 | 需要 | 只有第一次下載模型需要 |
| 隱私 | 音訊與文字送到雲端 | 不離開電腦 |
| 介面 | PyQt6 | tkinter（Python 內建） |

### 1-3. 不在範圍內

- 流式逐字顯示（講到一半就出字）：本產品是「講完一句才出字」的準即時字幕。
- 講者分離（標示誰在講話）。
- 語音輸入打字（曾實作，依需求移除）。
- macOS／Linux。

## 2. 使用情境

| 編號 | 情境 | 建議設定 |
|---|---|---|
| UC-1 | 線上會議中聽懂對方（英／日／韓文）在講什麼 | 收音：系統聲音；講者語言：中＋該外語 |
| UC-2 | 中文會議的即時字幕與逐字稿 | 收音：系統聲音或麥克風；講者語言：只勾中文 |
| UC-3 | 多語交替的會議（這句英文、下一句換人講日文） | 講者語言：勾所有可能出現的語言 |
| UC-4 | 看外語影片時顯示中文字幕 | 收音：系統聲音；講者語言：該外語 |
| UC-5 | 會議中自己和對方的話都要字幕 | 收音：兩者混音（戴耳機） |

## 3. 功能需求

### 3-1. 收音（FR-A）

| 編號 | 需求 | 狀態 |
|---|---|---|
| FR-A1 | 可擷取系統播放的聲音（WASAPI loopback），不需要虛擬音效線 | ✅ |
| FR-A2 | 可擷取麥克風 | ✅ |
| FR-A3 | 可同時擷取兩者並混音 | ✅ |
| FR-A4 | 可分別選擇麥克風、系統聲音裝置，或跟隨 Windows 預設裝置 | ✅ |
| FR-A5 | 設定的裝置已不存在或種類不符時，改用系統預設並提示 | ✅ |
| FR-A6 | 執行中裝置中斷、麥克風停止送資料、或 Windows 預設裝置被切換時，自動重新連接（約 1 秒內） | ✅ |
| FR-A7 | 暫時沒有任何裝置時持續重試（每 2 秒），插回後自動接上 | ✅ |
| FR-A8 | 可選擇另存 WAV 錄音（16 kHz 單聲道；暫停期間不錄） | ✅ |

### 3-2. 斷句（FR-B）

| 編號 | 需求 | 預設 | 狀態 |
|---|---|---|---|
| FR-B1 | 以 VAD 偵測停頓，講者停頓即輸出整句 | 停頓 500 ms | ✅ |
| FR-B2 | 句首保留前段音訊，避免吃掉第一個字 | 300 ms | ✅ |
| FR-B3 | 太短的聲音（咳嗽、敲鍵盤）不辨識 | < 250 ms | ✅ |
| FR-B4 | 講者連續講不停時主動斷句：超過 4 秒後短換氣即斷句 | 換氣 200 ms | ✅ |
| FR-B5 | 仍無停頓時在最近 1.5 秒內最安靜處切開，剩餘音訊接到下一句（不掉字） | 上限 8 秒 | ✅ |
| FR-B6 | 系統聲音中斷（沒有播放）時結束進行中的句子 | 0.6 秒 | ✅ |

### 3-3. 語音辨識（FR-C）

| 編號 | 需求 | 狀態 |
|---|---|---|
| FR-C1 | 本機 CPU 辨識，預設 Whisper small INT8；可改其他 Whisper 模型 | ✅ |
| FR-C2 | 講者語言可勾選中／英／日／韓；只勾一種時固定該語言 | ✅ |
| FR-C3 | 勾多種時每句獨立判斷語言，且只在勾選的語言之間選擇 | ✅ |
| FR-C4 | 短句信心不足時沿用上一句的語言（限勾選的語言） | ✅ |
| FR-C5 | 中英夾雜的句子判定為中文（直接顯示、不翻譯） | ✅ |
| FR-C6 | 中文結果轉為台灣繁體用語、全形標點（可關閉） | ✅ |
| FR-C7 | 過濾 Whisper 幻覺句（例如「ご視聴ありがとうございました」）與重複輸出 | ✅ |
| FR-C8 | 提示詞（專有名詞）可提高辨識率 | ✅ |
| FR-C9 | 只編碼實際音訊長度以縮短延遲；重複輸出時自動改用完整 30 秒視窗重試 | ✅ |

### 3-4. 翻譯（FR-D）

| 編號 | 需求 | 狀態 |
|---|---|---|
| FR-D1 | 英／日／韓翻成繁體中文（台灣用語），本機 CPU 執行 | ✅ |

| FR-D4 | 一段含多個句子時逐句翻譯，避免漏翻 | ✅ |

## 4. 非功能需求與實測結果

測試環境：Intel Core i7-1255U（15 W 筆電，2 大核＋8 小核，1.7 GHz）、16 GB 記憶體、
背景執行瀏覽器與會議軟體、Whisper small INT8、4 執行緒、`beam_size = 1`。

### 4-1. 效能

| 指標 | 目標 | 實測 |
|---|---|---|
| 講完一句到原文出現 | ≤ 1 秒 | **0.3～0.8 秒**（含 0.5 秒停頓判斷） |
| 講完一句到中文翻譯出現 | ≈ 1 秒 | **約 0.9 秒**（NLLB 600M） |
| 一般句子（2～5 秒）辨識時間 | — | 0.5～0.9 秒（改善前 4～7 秒） |
| 長句（11～15 秒）辨識時間 | — | 1.5～2.5 秒 |
| 翻譯時間 | — | 600M 約 0.8 秒／句；1.3B 約 1.4 秒／句 |
| 連續 18 秒不停頓的語音 | 主動斷句 | 切成 3 段（5～7 秒），都切在換氣處 |
| 裝置中斷到自動重新連接 | ≤ 2 秒 | 0.6～0.8 秒 |
| 模型載入（已下載） | — | 約 2～4 秒 |
| 模型下載 | — | 兩個模型共約 1.1 GB，實測約 130 秒（約 10 MB/s） |

### 4-2. 準確度

| 測試 | 結果 |
|---|---|
| 中英交替測試（4 句，TTS） | 4/4 文字與語言正確 |
| 中英夾雜（2 句） | 2/2 判定為中文、英文單字原樣保留 |
| 日文（JSUT 語料 10 句，勾中英日韓） | 語言判斷 10/10；字元錯誤率中位數 13%（錯誤多為同音異字） |
| 韓文（Zeroth Korean 10 句，勾中英日韓） | 語言判斷 10/10；字元錯誤率中位數 8.5%（部分是數字寫法差異，例如「삼 월」vs「3월」） |

### 4-3. 其他

| 項目 | 規格 |
|---|---|
| 程式大小 | 資料夾約 230 MB，zip 約 94 MB |
| 模型大小 | 辨識 small 約 470 MB；翻譯 600M 約 600 MB（1.3B 約 1.4 GB，選用） |
| 相依軟體 | 無（Python、Visual C++ 執行檔都已打包） |
| 網路 | 只有第一次下載模型時需要 |

| 自動測試 | 21 項（pytest，不需要模型和音效卡） |

## 6. 已知限制

| 編號 | 限制 | 因應 |
|---|---|---|
| L-1 | 準即時：講完一句才出字 | 調低 `end_silence_ms`；講太久時自動斷句 |
| L-2 | 多人同時說話只辨識較大聲的一方，不分講者 | — |
| L-3 | 本機翻譯品質不如雲端大型模型，偶爾漏翻或用詞生硬 | 改用 NLLB 1.3B |
| L-4 | 日文同音字錯誤較多（small 模型的限制） | 提示詞加專有名詞；較大模型（CPU 上較慢） |
| L-5 | 只有漢字的日文短句可能被判成中文 | 不會出現中文時不要勾中文 |
| L-6 | 強制斷句時一句話可能分成兩段字幕與翻譯 | 調高 `max_utterance_s` |
| L-7 | 在設定裡指定了特定裝置且它被拔掉時，改用系統預設裝置 | 選「（系統預設）」 |
| L-8 | 程式沒有數位簽章，第一次執行會出現 Windows 安全提示 | 「其他資訊」→「仍要執行」 |
| L-9 | 只在一台開發電腦上實測；尚未在其他硬體、真實拔插裝置上驗證 | — |

## 7. 技術選型

| 元件 | 選擇 | 理由 |
|---|---|---|
| 語音辨識 | faster-whisper 1.2（CTranslate2 4.9）、Whisper small INT8 | CPU 上最快的 Whisper 實作之一；INT8 量化；多語言 |
| 翻譯 | NLLB-200 distilled（CTranslate2 INT8） | 一個模型涵蓋英日韓→中；和辨識共用同一套推論引擎，不需要 PyTorch |
| VAD | webrtcvad | 輕量、逐 30 ms 判斷，適合即時 |
| 收音 | PyAudioWPatch | 支援 WASAPI loopback（不需虛擬音效線） |
| 重新取樣 | soxr | 高品質串流重新取樣 |
| 簡繁轉換 | OpenCC（s2twp） | 台灣用語 |
| 介面 | tkinter | Python 內建，打包較小 |
| 打包 | PyInstaller（資料夾版） | 不需要 Python；啟動快 |
| 預設裝置偵測 | Windows Core Audio（ctypes） | PortAudio 不會偵測執行中的裝置變更 |
