# 即時字幕（本機 CPU）使用說明書

把電腦正在播放的聲音（Teams／Zoom／Google Meet 會議、YouTube、影片）或麥克風收到的聲音，
即時轉成**大字幕**顯示在螢幕上：中文直接顯示，英文／日文／韓文翻成繁體中文並附上原文。
全部在自己的電腦上用 CPU 運算，**不需要顯示卡、不需要 API 金鑰、聲音和文字都不會傳到網路上**。

## 1. 運作原理（30 秒看懂）

```
 講者說話 ──► 收音 ──► 偵測停頓（約 0.5 秒）──► 語音辨識 ──► 是外語？──是──► 翻成中文 ──► 大字幕＋逐字稿
                                                 （本機 CPU）     │                （本機 CPU）
                                                                 └──否（中文、中英夾雜）──────► 大字幕＋逐字稿
```

- **準即時**：講者講完一句、停頓約半秒，整句字幕才會出現（不是一個字一個字跳）。整句辨識比較準。
- 講者一直講不停時，程式會在**換氣處主動斷句**，不會累積成一大段才出字幕。
- 在一般筆電（Intel i7-1255U）上實測：講完後約 **0.3～0.8 秒**出現原文，約 **0.9 秒**出現中文翻譯。

## 2. 第一次安裝

### 2-1. 需要的東西

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows 10 或 11（64 位元） |
| 記憶體 | 建議 8 GB 以上 |
| 顯示卡 | 不需要 |
| 硬碟空間 | 程式約 230 MB＋模型約 0.5～1.1 GB |
| 網路 | 只有第一次下載模型時需要 |

### 2-2. 安裝（一般使用者：用打包好的程式）

1. 到 GitHub 的 **Releases** 頁面下載 `LiveSubtitle.zip`（約 94 MB）。
2. 解壓縮到任何資料夾，例如 `桌面\LiveSubtitle`。
3. 雙擊 `LiveSubtitle.exe`。

> 第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」：按「**其他資訊**」→「**仍要執行**」。
> 這是因為程式沒有購買數位簽章，不是病毒。

不需要安裝 Python、Visual C++ 或其他任何軟體。

### 2-3. 安裝（開發者：從原始碼執行）

需要 Python 3.11 以上。

```powershell
git clone https://github.com/donny2582/cpu-subtitle
cd cpu-subtitle
powershell -ExecutionPolicy Bypass -File scripts\setup.ps1
```

之後雙擊 `start.bat`，或執行 `scripts\run.ps1`。

## 3. 第一次使用：下載模型

程式本身不包含模型。**第一次按「▶ 開始字幕」時**會自動下載到程式旁邊的 `models\` 資料夾：

| 模型 | 大小 | 何時下載 |
|---|---|---|
| 語音辨識（Whisper small） | 約 470 MB | 一定會下載 |
| 翻譯（NLLB 600M） | 約 600 MB | 有勾英文／日文／韓文時才下載 |

- 下載時狀態列會顯示進度，例如「下載語音辨識模型中… 50%（233 / 464 MB，10.4 MB/s）」。
- 下載一次之後，**之後開啟都直接使用，不再下載，也不需要網路**。
- 把整個資料夾（含 `models\`）複製到別台電腦，那台電腦就不用再下載。
- 第一次使用時沒有網路，會跳出提示「需要網路下載模型」。

## 4. 控制視窗說明

```
┌─────────────────────────────────────────────────────────────┐
│ [▶ 開始字幕] [⏸ 暫停]   ● 聆聽中                              │
│                        音量 ▓▓▓▓▓░░░░   辨識中 1 句            │
├─────────────────────────────────────────────────────────────┤
│ 〔辨識與翻譯〕〔字幕外觀〕                                       │
│  模型、講者語言、收音來源、裝置、紀錄、停頓出字、效能、翻譯模型…  │
├─────────────────────────────────────────────────────────────┤
│ [儲存設定] [開啟逐字稿資料夾] [測試 CPU 速度]                    │
├─────────────────────────────────────────────────────────────┤
│ 辨識結果：每句的時間、語言、原文、中文翻譯、花了幾秒              │
└─────────────────────────────────────────────────────────────┘
```

| 區域 | 說明 |
|---|---|
| ▶ 開始字幕／■ 停止 | 開始或停止收音與辨識 |
| ⏸ 暫停／▶ 繼續 | 暫停時不辨識、不錄音；講到一半的句子會丟掉 |
| 狀態燈 | 未啟動／載入模型中／下載中（百分比）／聆聽中／已暫停／已重新連接 |
| 音量表 | 有聲音進來時會跳動；完全不動代表收音來源選錯 |
| 辨識中 N 句 | 還在排隊等辨識的句子數；一直增加代表電腦跟不上 |
| 辨識結果 | 每句的語言、原文、翻譯與耗時（最多保留 2000 行） |

「辨識與翻譯」分頁的設定**在執行中不能修改**（要先停止）；「字幕外觀」分頁**隨時可改、立即套用**。
調整後按「**儲存設定**」才會寫進 `config.toml`，下次開啟沿用。

## 5. 日常使用

1. 雙擊 `LiveSubtitle.exe`。
2. 確認「講者語言」與「收音來源」（見第 6、7 節）。
3. 按「▶ 開始字幕」，狀態變成「● 聆聽中」。
4. 開始會議或播放影片，字幕出現在螢幕下方。
5. 結束時按「■ 停止」。

### 5-1. 字幕視窗操作

| 操作 | 效果 |
|---|---|
| 滑鼠拖曳 | 移動字幕位置（以底邊為準，句子變多時往上長，不會超出螢幕） |
| 右鍵 | 選單：字放大、字縮小、清除字幕、位置重設到螢幕下方、暫時隱藏（下一句再出現） |
| Ctrl＋滾輪 | 調整字級 |

字幕視窗不會搶走鍵盤焦點：點到字幕，也不會影響你正在打字的視窗。

### 5-2. 快捷鍵（任何視窗都有效）

| 快捷鍵 | 功能 |
|---|---|
| `Ctrl + Alt + F9` | 暫停／繼續 |
| `Ctrl + Alt + Q` | 停止 |

被其他程式占用時，辨識結果區會顯示警告，可以在 `config.toml` 的 `[hotkey]` 改成別的組合。

### 5-3. 逐字稿與錄音

- 每次按「開始字幕」都會在 `transcripts\` 建立一個逐字稿，檔名是開始時間，例如 `20261125_103000.txt`。
- 格式：

  ```
  [10:30:05] [en] Good morning everyone. Let's start the weekly project meeting.
             [中] 我們開始每週的專案會議。
  [10:30:12] [zh] 我們先來看一下這個月的銷售報告
  ```
- 勾選「同時存錄音檔」時，會另外存一個同名的 `.wav`（約每小時 115 MB，暫停期間不錄）。
- 按「開啟逐字稿資料夾」可以直接打開。

### 5-4. 換耳機／喇叭

執行中拔掉耳機、插上新的麥克風，或在 Windows 切換預設喇叭時，程式會在**約 1 秒內自動重新連接**，
辨識結果區顯示「🔄 已自動重新連接：裝置名稱」，不需要重新按開始。暫時沒有任何裝置時，每 2 秒重試一次。

## 6. 講者語言怎麼勾

「講者語言」= **講者可能會講的語言**（中文／英文／日文／韓文）。

| 勾選 | 程式怎麼做 | 適合 |
|---|---|---|
| 只勾一種（例如只勾中文） | 固定用這個語言辨識，不判斷語言 | **最快、最準**；只有一種語言的場合 |
| 勾多種 | 每一句只在勾選的語言之間自動判斷 | 多語交替的會議（這句英文、下一句換人講日文） |

| 講者講的是 | 字幕顯示 |
|---|---|
| 中文 | 直接顯示中文 |
| 中英夾雜（「這個 deployment 我們明天再 review」） | 直接顯示，不翻譯 |
| 英文／日文／韓文 | **中文大字＋原文小字**（原文先出現，翻譯好後補上中文） |

> ⚠️ **只勾實際會出現的語言。** 勾太多會增加誤判（例如很短的中文被判成日文）；
> 有人講了沒勾的語言時，會被硬套成勾選的語言而變成錯字。

### 翻譯模型

| 選項 | 速度（一般筆電） | 說明 |
|---|---|---|
| 快（NLLB 600M，預設） | 約 0.8 秒／句 | 意思大致正確，用詞偶爾生硬 |
| 準（NLLB 1.3B） | 約 1.4 秒／句 | 用詞較自然；第一次使用要另外下載約 1.4 GB |

本機翻譯的品質比雲端大型模型差一些，偶爾會漏翻或用詞生硬（例如韓元被翻成美元）。

## 7. 收音來源：三種模式

| 模式 | 收的聲音 | 用途 |
|---|---|---|
| **系統聲音**（預設） | 電腦正在播放的聲音（WASAPI loopback） | Teams／Zoom 會議中**對方**講的話、YouTube、影片 |
| **麥克風** | 麥克風收到的聲音 | 現場有人講話、自己講話 |
| **兩者混音** | 系統聲音＋麥克風 | 會議中自己和對方都要辨識 |

- 兩者混音時**請戴耳機**，否則喇叭的聲音會被麥克風再收一次，同一句出現兩次。
- 麥克風與系統聲音可以各自選裝置；選「（系統預設）」會跟著 Windows 的預設裝置走。
- 插拔裝置後清單沒更新，按「重新整理」。

## 8. 字幕外觀

在「字幕外觀」分頁調整，**立即套用**；按「預覽字幕」可以先看效果。

| 設定 | 預設值 | 說明 |
|---|---|---|
| 樣式 | 灰底白字 | 另有黑底白字、白底黑字＋黑框、黑底黃字、黑框黑底白字；點色塊可自訂文字／底色／外框顏色 |
| 字型／字級／粗體 | 微軟正黑體／32／粗體 | 原文小字是中文字級的 55% |
| 外框粗細 | 0（無框） | 像素 |
| 圓角 | 18 | 像素，0 = 直角 |
| 透明 ↔ 不透明 | 0.70 | 越小越透明 |
| 同時顯示 | 2 句 | 1～6 句 |
| 寬度 | 螢幕寬度 80% | |
| 距底部 | 80 像素 | |
| 幾秒沒新句子就清除 | 10 秒 | 0 = 不清除 |
| 顯示語言標籤 | 關 | 每句前面加 [英]／[日]／[韓]／[中] |
| 中文下方小字顯示原文 | 開 | 外語句子的原文對照 |
| 滑鼠點擊穿透 | 關 | 開啟後滑鼠會直接點到字幕後面的視窗（不能拖曳，要從控制視窗關閉） |

## 9. 常見問題與錯誤排除

### 😶 按了開始，完全沒有字幕
1. 看**音量表**有沒有跳動。不動 → 收音來源選錯：會議或影片要選「系統聲音」，現場說話要選「麥克風」。
2. 會議軟體的聲音如果是從**另一個喇叭／耳機**出來，到「系統聲音」選對應的裝置。
3. 看「講者語言」有沒有勾到講者實際講的語言。

### 🌐 跳出「需要網路下載模型」
第一次使用要連網下載模型（見第 3 節）。連上網路後再按一次「開始字幕」。

### 🛡️ Windows 已保護您的電腦
按「其他資訊」→「仍要執行」。程式沒有數位簽章，不是病毒。

### 🔤 語言判斷錯（中文被當成日文等）
只勾實際會出現的語言；只有中文的場合只勾「中文」。

### ✂️ 句子被切得太碎／字幕太慢
調整「停頓出字」：句子太碎 → 調高到 700～800 ms；想更快 → 調低到 350～400 ms。

### 🐢 「辨識中 N 句」一直增加（電腦跟不上）
1. 按「測試 CPU 速度」，讓程式自動找出最快的執行緒數，再按「儲存設定」。
2. beam 設成 1。
3. 不要用 large-v3-turbo 等大模型。
4. 插上電源、Windows 電源模式改「最佳效能」、關掉吃 CPU 的程式。

### 🈳 翻譯怪怪的
本機翻譯有極限。「翻譯模型」改成「準（NLLB 1.3B）」會好一些（較慢）。

### 📍 字幕跑到看不到的地方
在字幕上按右鍵 →「位置重設到螢幕下方」；或在「字幕外觀」分頁按「位置重設」。

### 🖱️ 字幕點不到、無法拖曳
可能開啟了「滑鼠點擊穿透」，到「字幕外觀」分頁取消勾選。

### ⌨️ 快捷鍵沒反應
辨識結果區若顯示「這些快捷鍵被其他程式占用」，到 `config.toml` 的 `[hotkey]` 改成其他組合。

### 🔧 設定改壞了
程式會跳出「設定檔有問題」並暫時用預設值開啟。可以修正 `config.toml`，
或**直接刪掉 `config.toml`**，下次開啟會重新建立預設設定。

### 📂 模型或逐字稿不在程式資料夾裡
程式放在 `C:\Program Files` 這類沒有寫入權限、或路徑太長（超過 90 字元）的資料夾時，
模型、設定、逐字稿會改存到 `%LOCALAPPDATA%\LiveSubtitle`（在檔案總管網址列輸入就能開啟）。

### 📝 其他錯誤
錯誤紀錄在 `logs\voicetype.log`（超過 5 MB 會換新檔，前一份是 `voicetype.old.log`）。

## 10. 指令速查表

從原始碼執行時（打包版也可以把同樣的參數加在 `LiveSubtitle.exe` 後面，但它沒有主控台，
文字輸出會寫在 `logs\voicetype.log`）：

```powershell
scripts\run.ps1                                        # 開控制視窗
scripts\run.ps1 --cli                                  # 不開視窗，在終端機執行（只有中文）
scripts\run.ps1 --cli --languages zh,en,ja             # 講者可能講中／英／日；英日翻成中文
scripts\run.ps1 --cli --source both --languages zh,en  # 系統聲音＋麥克風混音（請戴耳機）
scripts\run.ps1 --list-devices                         # 列出麥克風／系統聲音裝置編號
scripts\run.ps1 --benchmark                            # 測出這台 CPU 最快的 cpu_threads
scripts\run.ps1 --file meeting.wav --languages zh,en   # 用音訊檔測試辨識＋翻譯
scripts\run.ps1 --silence-ms 400                       # 臨時改停頓出字的毫秒數
```
