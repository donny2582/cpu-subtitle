# 打包成 .exe 與在其他電腦使用

把程式打包成**不需要安裝 Python** 的 Windows 應用程式，拿到別台電腦直接執行。

---

## 1. 打包（在你自己的開發電腦上做）

### 需要

- 已經用 `scripts\setup.ps1` 建好 `.venv`
- Windows 10／11 64 位元

### 指令

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_exe.ps1
```

```powershell
# 不要產生 zip（只要資料夾）
powershell -ExecutionPolicy Bypass -File scripts\build_exe.ps1 -NoZip
```

產出：

| 檔案 | 大小 | 說明 |
|---|---|---|
| `release\LiveSubtitle\` | 約 230 MB | 程式資料夾，整個複製到別台電腦就能用 |
| `release\LiveSubtitle.zip` | 約 94 MB | 上面資料夾的壓縮檔，傳給別人用這個 |

### 打包了什麼、沒打包什麼

| 有打包 | 沒打包 |
|---|---|
| Python 執行環境、所有套件（faster-whisper、CTranslate2、PyAudioWPatch、webrtcvad、soxr、OpenCC、tokenizers…）、Visual C++ 執行檔 | **模型**（第一次使用時自動下載，見第 2 節） |
| `config.example.toml`、`使用說明.txt` | 你的 `config.toml`、逐字稿、紀錄檔 |

- 採用**資料夾版**（one-dir）而不是單一 exe：單一 exe 每次啟動都要先把幾百 MB 解壓到暫存資料夾，
  啟動慢、也容易被防毒軟體誤判。
- 排除了 `onnxruntime`（約 54 MB）：只有 faster-whisper 內建的 VAD 會用到，本程式用 WebRTC VAD。
- `LiveSubtitle.exe` 是**視窗程式**（沒有黑色主控台）；文字輸出與錯誤寫在 `logs\voicetype.log`。

### 打包相關檔案

| 檔案 | 用途 |
|---|---|
| `scripts\build_exe.ps1` | 一鍵打包：PyInstaller → 複製到 `release\` → 附上設定範本與使用說明 → 壓縮 zip |
| `packaging\LiveSubtitle.spec` | PyInstaller 設定（要收進來的資料檔、DLL、要排除的套件） |
| `packaging\launcher.py` | exe 的進入點 |
| `packaging\使用說明.txt` | 放進發布資料夾、給使用者看的簡短說明 |

## 2. 在其他電腦使用

### 對方電腦需要

- Windows 10 或 11（64 位元）
- **不需要** Python、Visual C++ 或任何其他軟體
- 第一次使用時需要網路（下載模型）

### 步驟

1. 把 `LiveSubtitle.zip` 傳給對方，解壓縮到任何資料夾（例如桌面）。
2. 雙擊 `LiveSubtitle.exe`。
   出現「Windows 已保護您的電腦」時按「其他資訊」→「仍要執行」（程式沒有數位簽章）。
3. 勾選講者語言、選收音來源，按「▶ 開始字幕」。
4. **第一次**會自動下載模型，狀態列顯示百分比：

   | 模型 | 大小 | 何時下載 |
   |---|---|---|
   | 語音辨識（Whisper small） | 約 470 MB | 一定會下載 |
   | 翻譯（NLLB 600M） | 約 600 MB | 有勾英文／日文／韓文時 |

5. 之後開啟都直接使用，**不再下載、不需要網路**。

> 想讓對方完全不用網路：先在自己電腦用過一次（模型下載好），再把整個 `LiveSubtitle` 資料夾
> 連同 `models\`（約 1.3 GB）複製給對方。

### 逐字稿存在哪裡？

程式資料夾裡的 `transcripts\`。在控制視窗按「開啟逐字稿資料夾」就能打開。

### 程式放在「不能寫入」的地方時

放在 `C:\Program Files` 這類需要系統管理員權限的資料夾，或資料夾路徑超過 90 字元時，
模型、設定、逐字稿、紀錄會改存到 **`%LOCALAPPDATA%\LiveSubtitle`**（在檔案總管網址列輸入就能開啟）。
路徑太長時改存的原因：模型檔的路徑本身就約 150 字元，Windows 預設的路徑上限是 260 字元。

## 3. 更新到新版本

1. 下載新版 `LiveSubtitle.zip`。
2. 解壓縮後，用新的 `LiveSubtitle.exe` 與 `_internal\` **覆蓋**舊資料夾裡的同名檔案。
3. **保留** `models\`（不用重新下載）、`config.toml`（你的設定）、`transcripts\`（逐字稿）。

新版本多了設定項目時，`config.toml` 裡沒有的項目會自動使用預設值；
在控制視窗按「儲存設定」會把新項目補進 `config.toml`（原本的註解會保留）。

## 4. 常見問題

| 狀況 | 處理 |
|---|---|
| 雙擊 exe 後什麼都沒出現 | 看 `logs\voicetype.log`；防毒軟體第一次掃描可能要 10～30 秒 |
| 第一次跳出「需要網路下載模型」 | 連上網路後再按一次「開始字幕」；公司網路擋 huggingface.co 時，從別台電腦複製 `models\` 過來 |
| 下載到一半斷網 | 網路恢復後再按一次「開始字幕」，會接著已下載的部分繼續下載 |
| 防毒軟體把 exe 隔離 | 把程式資料夾加入例外；或請 IT 確認（PyInstaller 打包的程式偶爾會被誤判） |
| 設定檔改壞了 | 刪掉 `config.toml`，下次開啟會重新建立 |
| 要確認版本 | 看 GitHub Releases 上的版本號（例如 v0.1.0） |

開發者驗證打包結果的方式（不需要另一台電腦）：在 PATH 裡拿掉 Python、斷開網路代理的情況下執行
`LiveSubtitle.exe --file 測試.wav --languages zh,en`，並檢查程式載入的 DLL 只來自打包資料夾與 Windows 系統。
