即時字幕（本機 CPU）使用說明
================================

這個資料夾就是完整的程式，不需要安裝 Python 或其他軟體。
可以整個資料夾複製到隨身碟或其他電腦使用。

【第一次使用需要網路】
第一次按「開始字幕」時，程式會自動下載模型到這個資料夾裡的 models\：
  - 語音辨識模型：約 470 MB（一定會下載）
  - 翻譯模型：約 600 MB（有勾英文／日文／韓文時才下載）
下載時狀態列會顯示「已下載 xxx MB」，依網路速度約需數分鐘。
下載一次之後，之後開啟都直接使用，不會再下載，也不需要網路。
（把整個資料夾連同 models\ 複製到別台電腦，那台電腦就不用再下載。）

【系統需求】
- Windows 10 或 11（64 位元）
- 記憶體建議 8 GB 以上
- 不需要獨立顯示卡；CPU 越快，字幕出來越快

【開始使用】
1. 雙擊 LiveSubtitle.exe
   （第一次執行時 Windows 可能跳出「Windows 已保護您的電腦」：
     按「其他資訊」→「仍要執行」。這是因為程式沒有數位簽章，不是病毒。）
2. 在「辨識與翻譯」分頁勾選「講者語言」：
   - 只勾中文：固定用中文辨識，最快最準
   - 有勾英文／日文／韓文：這些語言會翻成中文，並以小字附上原文
   - 中文或中英夾雜的句子直接顯示，不翻譯
3. 選「收音來源」：
   - 系統聲音：會議軟體、YouTube、影片的聲音（預設）
   - 麥克風：現場有人說話
   - 兩者混音：兩種一起（請戴耳機，否則同一句會出現兩次）
4. 按「▶ 開始字幕」。講者講完一句、停頓約半秒，字幕就會出現在螢幕下方。

【字幕視窗】
- 可以直接用滑鼠拖曳到任何位置
- 在字幕上按右鍵：放大／縮小字、清除、位置重設、暫時隱藏
- Ctrl + 滑鼠滾輪：調整字級
- 顏色、透明度、圓角、字型等在「字幕外觀」分頁調整
- 調好後按「儲存設定」，下次開啟會沿用

【換耳機／喇叭】
執行中拔掉耳機、插上新的麥克風，或在 Windows 切換預設喇叭時，程式會在約 1 秒內自動重新連接，
不用重新按開始。暫時沒有任何裝置時，會每 2 秒重試一次，插回去就會接上。

【快捷鍵】
- Ctrl + Alt + F9：暫停／繼續
- Ctrl + Alt + Q：停止

【檔案位置】
- transcripts\   每次的逐字稿（.txt），勾選「同時存錄音檔」時也會有 .wav
- config.toml    設定檔（刪掉後下次開啟會恢復預設值）
- models\        語音辨識與翻譯模型（請勿刪除）
- logs\          發生問題時的錯誤紀錄

【第一次開啟比較慢？】
防毒軟體第一次會掃描程式與模型，可能需要 10～30 秒，之後就會正常。

【程式放在 C:\Program Files？】
如果程式所在的資料夾沒有寫入權限，模型、設定、逐字稿會改存到
%LOCALAPPDATA%\LiveSubtitle（在檔案總管網址列輸入這串就能開啟）。

【換成其他模型】
介面上可以選 large-v3-turbo（較準）或「準（NLLB 1.3B）」翻譯模型，
但這些模型沒有附在資料夾裡：第一次使用時需要網路自動下載（約 1.4～1.6 GB），
而且在一般筆電上會明顯比較慢。
